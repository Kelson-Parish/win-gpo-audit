Windows firewall starting defaults and role expectations

Normal defaults are enabled firewall profiles, blocking unmatched inbound traffic, allowing unmatched outbound traffic, accepting inbound allow rules and merging local rules. Managed policy can intentionally differ. Unresolved values are shown as unknown, not unsafe. This is a settings reference, not a fixed list of every firewall rule.

Automatic service expectations

Only core and selected-role services have state expectations. Other services still receive artifact checks. An unfamiliar service is not assumed to be unsafe. Manual startup is accepted for Windows Process Activation Service when it supports the website role. Microsoft Structured Query Language (SQL) Server Agent and third-party security products have deployment-specific requirements.
